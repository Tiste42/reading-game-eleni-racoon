# Full Audit — 2026-06-11

Source: parallel code/audio/design audits + research on best-in-class reading games.

## 1. Audio (the "errors in the sounds" problem)

Phoneme generation text lives in `scripts/generate-audio.ts:28-35`. Continuous sounds (s, m, n, l, r, f, v, z, sh, th) are generated correctly as stretched sounds ("ssss"). The problems:

| Phoneme | Generated as | Problem |
|---|---|---|
| t, p, d, b, g, c, k, j, ch | "tuh", "puh", etc. | Schwa added — teaches wrong sound, sabotages blending ("tuh-ah-puh" ≠ "tap") |
| x | "ks" | Not an isolable phoneme; teach only in word context |
| j | "juh" | Letter-name "jay" confusion risk |
| y | "yuh" | Consonant/vowel ambiguity |

Code bugs:
- `speech.ts:348-355` — missing audio file resolves silently (no sound, no fallback)
- `speech.ts:408-410` — phonemes in KNOWN_PHONEMES never fall back to browser TTS if file missing
- No audio ducking — music + speech play simultaneously at full volume
- `useGameSpeech.ts:16` — fixed 400ms delay before all speech

## 6. Research takeaways (what the best games do)

- **Starfall accelerating blend**: b...a...t → b..a..t → bat, faster each pass — the proven fusion-moment audio model. Pre-bake 3 speeds.
- **Successive blending** beats final blending for strugglers: /s/+/a/→"sa", "sa"+/t/→"sat". Halves working-memory load. Great as a drag-tiles-that-merge-and-speak mechanic.
- **Word chaining** (sat→sit→sip→tip) has ~2x effect size of letter-free phoneme work — PotionLab is the right idea, make it the W4 spine.
- **Model the correct answer via the character after errors** — only 4% of apps do this; cheapest big differentiator. Never just "try again."
- **Scaffold down on failure**: 2 misses → 4 choices become 2 → then Leni models. Difficulty spikes are a top abandonment driver.
- **Production > recognition**: drag-to-blend, build-the-word, say-it-aloud (record button) over tap-the-answer.
- **Rewards flow to the character** (dress Leni, treats for Leni) — relational rewards beat currency at age 4. Khan Kids/TYM pattern.
- **Reward = more content**: unlock a story or free-play game (Lalilo pattern), dodges overjustification effect.
- **Process praise** ("you sounded out every letter!") not person praise ("you're so smart").
- **Avoid**: streaks/timers/leaderboards at age 4; celebrations >3s; praise-everything (Homer's flaw).
- Session structure: 5-8 micro-activities of ~45s each, ending in a closing ritual (Duolingo ABC).
